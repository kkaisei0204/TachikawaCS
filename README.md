# TachikawaCS - 立川市飲食店混雑状況確認システム

## 概要
立川市内の飲食店の混雑状況をリアルタイムで確認できるWebアプリです。
ユーザー登録（サインアップ）することで、混雑状況の投稿まで
ユーザー視点で完結して利用できるシステムです。
専門学校の卒業制作として、5人チームで開発しました。

## 使用技術
- Python
- Flask
- HTML / CSS
- JavaScript
- SQL（データベース）

## 主な機能
- 飲食店の混雑状況の確認（ログイン不要）
- AI分析機能（ログイン不要）
- 投稿への評価機能（ログイン不要）
- ユーザー登録・ログイン（サインアップ機能）
- 混雑状況の投稿（要サインアップ）

## 担当箇所
- 要件定義・機能設計への参加
- バックエンド開発を中心に担当

## 工夫した点
- エラーに直面した際、デジタル教材や検索エンジンを活用して原因を調査
- チームメンバーと意見を出し合いながら問題を解決

## 成果
- 学内のコンテストで8チーム中1位の評価を獲得
